服务条款 ​

最后更新日期：2026 年 9 月 10 日

欢迎使用 ETS2LA-CN 提供的 Discord App 及相关消息同步服务。

本服务条款（以下简称“本条款”）适用于您使用 ETS2LA-CN Discord App（以下简称“本应用”）及相关消息同步服务的行为。

本应用主要用于将指定 Discord 频道中的社区消息同步至指定的 KOOK 频道。

使用本应用即表示您同意遵守本条款以及适用的法律法规、Discord 的相关政策和 KOOK 的相关规则。

1. 服务说明 ​

本应用主要提供以下功能：

  • Discord 消息接收；
  • Discord 与 KOOK 之间的消息同步；
  • 消息格式转换；
  • 与消息同步相关的运行状态和错误处理。

本应用不属于 Discord Inc. 或 KOOK 官方产品，也不代表 Discord 或 KOOK。

服务可能根据实际需要进行更新、修改、暂停或终止。

2. 使用资格 ​

您在使用本应用时必须：

  • 遵守适用的法律法规；
  • 遵守 Discord 的服务条款及相关政策；
  • 遵守 KOOK 的服务条款及相关政策；
  • 遵守您所在 Discord 服务器的规则；
  • 不利用本应用从事违法、欺诈、骚扰、滥用或其他违反平台规则的行为。

3. Discord 服务器管理员 ​

本应用是否能够访问 Discord 服务器及其频道取决于服务器管理员授予的权限。

服务器管理员负责决定：

  • 是否安装本应用；
  • 将本应用添加到哪些服务器；
  • 本应用可以访问哪些频道；
  • 哪些消息可以被同步；
  • 消息同步的目标 KOOK 频道。

我们建议服务器管理员仅授予本应用完成实际功能所需要的最低权限。

4. 消息同步 ​

本应用的核心功能是将 Discord 消息同步至 KOOK。

由于 Discord 和 KOOK 属于不同的平台，消息在同步过程中可能发生以下变化：

  • Markdown 或格式发生变化；
  • 图片、附件或 Embeds 的显示方式发生变化；
  • 用户名称或头像显示方式发生变化；
  • 某些 Discord 特有的消息元素无法在 KOOK 中完全还原；
  • 消息顺序可能因网络延迟等原因发生变化；
  • 消息可能因为平台限制、网络错误或服务故障而无法同步。

因此，我们不保证 Discord 消息能够在 KOOK 中完全一致地呈现。

5. 用户内容 ​

您在 Discord 或 KOOK 中发布的内容仍然由您自行负责。

本应用不会因为消息同步而取得您内容的所有权。

但是，为实现跨平台消息同步，本应用可能需要对消息进行临时处理、格式转换或传输。

您应确保自己拥有发布和传播相关内容所需的权利，并不得利用本应用传播违法或侵犯他人权利的内容。

6. 禁止行为 ​

您不得利用本应用：

  • 从事违法活动；
  • 侵犯他人的知识产权或其他合法权益；
  • 进行骚扰、威胁或恶意攻击；
  • 发送垃圾信息；
  • 规避 Discord 或 KOOK 的安全机制；
  • 滥用 Discord API 或 KOOK API；
  • 尝试获取本应用无权访问的数据；
  • 干扰本应用或其运行基础设施；
  • 以其他方式违反 Discord、KOOK 或适用法律法规的要求。

我们保留在必要情况下限制或终止相关服务使用的权利。

7. 服务可用性 ​

我们会尽合理努力保持服务稳定运行，但不保证服务：

  • 永远可用；
  • 不会出现中断；
  • 不会出现延迟；
  • 不会发生错误；
  • 始终兼容 Discord 或 KOOK 的最新版本。

如果 Discord、KOOK 或相关 API 发生变化，本应用可能需要进行技术调整，并可能暂时影响部分功能。

8. 第三方服务 ​

本应用依赖 Discord、KOOK 以及其他可能的第三方基础设施。

第三方服务可能独立修改其：

  • API；
  • 服务条款；
  • 隐私政策；
  • 访问限制；
  • 技术规范；
  • 服务可用性。

由于这些因素不完全由我们控制，因此我们无法保证本应用始终能够使用所有第三方功能。

本应用不得被理解为授予您任何未明确授予的知识产权许可。

对于第三方服务、软件、商标或内容，其知识产权仍归相应权利人所有。

10. 免责声明 ​

我们不保证本应用完全没有错误，也不保证消息同步一定及时、完整或准确。

由于以下原因造成的服务问题，我们不承担超出适用法律允许范围的责任：

  • Discord 服务故障；
  • KOOK 服务故障；
  • 网络故障；
  • API 变化；
  • 第三方基础设施故障；
  • 不可抗力；
  • 用户或服务器管理员配置错误；
  • 超出我们合理控制范围的其他情况。

11. 服务变更与终止 ​

我们可以根据实际需要：

  • 更新本应用；
  • 修改服务功能；
  • 暂停部分功能；
  • 停止某些消息同步；
  • 终止本应用服务。

如果服务终止，我们会在合理范围内处理仍在运行中的相关服务。

本应用对信息的收集、使用和处理方式由我们的《隐私政策》规定。

使用本应用时，您仍然必须遵守 Discord 和 KOOK 各自的服务条款、开发者政策、社区规则以及其他适用政策。
