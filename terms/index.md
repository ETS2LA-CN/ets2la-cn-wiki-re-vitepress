# 服务条款

**最后更新日期：2026 年 9 月 10 日**

欢迎使用 ETS2LA-CN 提供的 Discord App 及相关消息同步服务。

本服务条款（以下简称“本条款”）适用于您使用 ETS2LA-CN Discord App（以下简称“本应用”）及相关消息同步服务的行为。

本应用主要用于将指定 Discord 频道中的社区消息同步至指定的 KOOK 频道。

使用本应用即表示您同意遵守本条款以及适用的法律法规、Discord 的相关政策和 KOOK 的相关规则。

## 1. 服务说明

本应用主要提供以下功能：

- Discord 消息接收；
- Discord 与 KOOK 之间的消息同步；
- 消息格式转换；
- 与消息同步相关的运行状态和错误处理。

本应用不属于 Discord Inc. 或 KOOK 官方产品，也不代表 Discord 或 KOOK。

服务可能根据实际需要进行更新、修改、暂停或终止。

## 2. 使用资格

您在使用本应用时必须：

- 遵守适用的法律法规；
- 遵守 Discord 的服务条款及相关政策；
- 遵守 KOOK 的服务条款及相关政策；
- 遵守您所在 Discord 服务器的规则；
- 不利用本应用从事违法、欺诈、骚扰、滥用或其他违反平台规则的行为。

本应用是否能够访问 Discord 服务器及其频道取决于服务器管理员授予的权限。

服务器管理员负责决定：

- 是否安装本应用；

我们建议服务器管理员仅授予本应用完成实际功能所需要的最低权限。

## 4. 消息同步

本应用的核心功能是将 Discord 消息同步至 KOOK。

由于 Discord 和 KOOK 属于不同的平台，消息在同步过程中可能发生以下变化：

- Markdown 或格式发生变化；
- 图片、附件或 Embeds 的显示方式发生变化；
- 用户名称或头像显示方式发生变化；
- 某些 Discord 特有的消息元素无法在 KOOK 中完全还原；
- 消息顺序可能因网络延迟等原因发生变化；
- 消息可能因为平台限制、网络错误或服务故障而无法同步。

因此，我们不保证 Discord 消息能够在 KOOK 中完全一致地呈现。

## 5. 用户内容

您在 Discord 或 KOOK 中发布的内容仍然由您自行负责。

本应用不会因为消息同步而取得您内容的所有权。

但是，为实现跨平台消息同步，本应用可能需要对消息进行临时处理、格式转换或传输。

您应确保自己拥有发布和传播相关内容所需的权利，并不得利用本应用传播违法或侵犯他人权利的内容。
