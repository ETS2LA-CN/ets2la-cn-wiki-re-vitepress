## 1.安装
- ## 1.1 已完成准备工作
双击运行刚才下载的安装程序，可能会出现`Windows defender`的提示，直接点击`更多信息`，展开之后选择`仍要运行`即可。
![](https://tuchuang.ets2la.cn/25-12/20250721084016.png)  
然后会进入到安装向导，点击 `下一步` 即可  
![](https://tuchuang.ets2la.cn/csharp/20260902103726262.png)
勾选 `我接受许可协议中的条款` 并点击 `下一步`
![](https://tuchuang.ets2la.cn/csharp/20260902103806945.png)
点击 `安装` 来安装软件
![](https://tuchuang.ets2la.cn/csharp/20260902103839288.png)
这一步请慢慢等待 应该很快会安装成功
![](https://tuchuang.ets2la.cn/csharp/20260902103855166.png)
安装完成后默认勾选 `启动ETS2LA` ，然后点击 `完成`
![](https://tuchuang.ets2la.cn/csharp/20260902104009805.png)

- ## 1.2 未完成准备工作
双击安装程序之后可能会出现会`Windows defender`的提示，直接点击`更多信息`，展开之后选择`仍要运行`即可。
![](https://tuchuang.ets2la.cn/25-12/20250721084016.png)  
弹出 `需要其他组件` 的提示框，选择安装程序会自动下载并安装.NET10（如果期间弹出UAC则手动允许即可）。
![](https://tuchuang.ets2la.cn/csharp/20260902103333221.png)
然后会进入到安装向导，点击 `下一步` 即可  
![](https://tuchuang.ets2la.cn/csharp/20260902103726262.png)
勾选 `我接受许可协议中的条款` 并点击 `下一步`
![](https://tuchuang.ets2la.cn/csharp/20260902103806945.png)
点击 `安装` 来安装软件
![](https://tuchuang.ets2la.cn/csharp/20260902103839288.png)
这一步请慢慢等待 应该很快会安装成功
![](https://tuchuang.ets2la.cn/csharp/20260902103855166.png)
安装完成后默认勾选 `启动ETS2LA` ，然后点击 `完成`
![](https://tuchuang.ets2la.cn/csharp/20260902104009805.png)

::: tip 提示
目前对于A卡可能会无法渲染路径线的问题 这不是你的问题 需耐心等待作者修复即可
:::
